# Changelog

## 0.3.0 — 2026-11-26

与技能 `sales-worklog` 0.3.0 配套：**报告正式定位为汇报件，模板按 leader 的阅读方式重写**。

- 明确读者：六种报告全部是写给 leader 的汇报件，台账才是自己的清单。报告里的「下一步」改成 leader 能预期的节奏，自己的待办不再搬进报告。
- 新增「需要你拍板」：周报以上必须有，每项**两个选项加期限**。只给一个是请示，给三个以上等于没给。
- 小标题从标签改判断：`某科技·张三 —— 报价（本周推进）` → `某科技·张三 · 报价 · 卡在等预算，已 24 天`。配三条验收测试（标题串连读 / 决定测试 / 删段测试）。
- 新增客户原话硬配额：日 1 / 周 2 / 月 3 / 季 5 / 年 8，只能取台账 `evidence[].quote`。
- 新增 `E_QUOTE_NOT_GROUNDED`：`quote` 去标点后必须是该消息原文的连续片段，编一句概括会直接报错。省略号分段核对，PII 打码（`138****1234`）不误伤。
- 新增两个派生状态：`regressed`（阶段序号下降，比停滞更紧急，进风险段第一行）、`revived`（沉默超 2 倍阈值后回来，标「复活」）。
- 证据密度随周期递减：日/周每条挂时间锚；月报以上只给金额与反直觉结论挂，其余进「证据索引」。
- 每份报告加一行头信息（窗口 / 台账版本 / 覆盖 / 生成时间），便于归档比对。
- 报告新增「客户原话」段（日报）与「证据索引」段（月报以上）。
- `ledger.md` 补 `evidence.quote` 口径（原文子串、≤60 字、优先客户方、PII 打码怎么核）。
- 红线 11 → 13 条：新增「不编原话」「不交只描述不请示的报告」。
- `selftest.sh` 断言 33 → 39 项，新增原话造假、阶段回退、复活三组断言，全绿。
- **升级注意**：`quote` 现在是硬闸。老台账里若有概括式的 quote，跑 `check_ledger.py` 会报 `E_QUOTE_NOT_GROUNDED`，需要回原文截取或删掉该 quote。

## 0.2.0 — 2026-11-25

与技能 `sales-worklog` 0.2.0 配套：**支持客户群**。

- 采集可以把客户群一起采（`--groups`），窗口稿按 `sender_is_external` 把每条消息分成 **我 / 我方同事 / 客户方 / 未标注** 四类，避免把同事的话当成客户回应。
- 分边未知（该字段全空）时不产出 `silent` / `awaiting_*` 结论，改打 `side_unknown` + `awaiting_check`，并在窗口稿里挂警告行。
- `window.json` 新增 `totals.group_sides`、`coverage.customer_groups`、`coverage.groups_side_unknown`。
- 新增群聊规则：哪些群不能进台账（部门群/通知群/跨客户行业群）、同一客户既有单聊又有群时怎么建 item、群里同事推进的事项 `next_action` 要写清谁做。
- 红线从 10 条增到 11 条，新增「不把群里同事当客户」；降级表补两行（客户群混采、分边未知）。
- `prepare_window.py` 新增 `--week` / `--month` 快捷周期参数（ISO 周 / 自然月，只写参数名 = 本周/本月）。
- 修「周期末在未来时静默天数被多算」：基准改为 `min(周期末, 今天)`，写进 `window.ref_date`，窗口稿在周期未结束时打印一行说明。
- 统一群分边的展示措辞：`display_sender` 不再自带一份映射，改走 `side_word()`（原先消息行写「我方」、名册写「我方同事」）。
- `selftest.sh` 断言 12 → 33 项。前 28 项本机实测全绿（真实仓库 `我 10 / 对方 10`）；后 5 项（`--week`/`--month`）待复跑。
- 头像换成插画版（深蓝圆角卡 + 戴耳麦的销售手持清单），512×512 / 约 300KB；`make_avatar.py` 保留为缺图时的兜底。
- `author.email` 改为 `2283743369@qq.com`；交付文档去掉上游项目名与个人绝对路径。
